# MySQL 切换说明（2026-09-30）

> 本文档是对 `docs/system_design.md`（PostgreSQL 版设计）的**切换补充**：数据层已从便携版 PostgreSQL 16 整体切换到本机 MySQL 9.7.2。原设计中的架构分层、API 契约、加密方案均不变，仅驱动与 SQL 方言更换。

## 1. 切换背景

老总本机已有 MySQL 实例（9.7.2，端口 3306，账号 transfer），决定弃用便携版 PostgreSQL（其后台进程会随会话退出、重启需手动拉起，运维负担高），统一收敛到常驻的本地 MySQL。

## 2. 变更清单

| 项 | 变更 |
|---|---|
| 驱动 | `pg` 已卸载 → `mysql2@^3.24.5`（mysql2/promise 连接池，globalThis 单例） |
| `app/lib/db.ts` | 连接池改 mysql2；手工解析 DATABASE_URL；`timezone: "Z"`（DATETIME 按 UTC 读写）；`FOUND_ROWS`（UPDATE 返回命中行数，保证存在性判定） |
| `app/lib/bootstrap.ts` | DDL 改 MySQL 方言：JSONB→JSON、TIMESTAMPTZ→DATETIME(3)、`ON CONFLICT DO NOTHING`→`INSERT IGNORE`；updated_at 由 `ON UPDATE CURRENT_TIMESTAMP(3)` 自动维护 |
| `app/lib/meetingRepo.ts` | 占位符 `$n`→`?`；upsert 改 `ON DUPLICATE KEY UPDATE`；LIMIT 白名单化后内联 |
| `app/lib/settingsRepo.ts` | 占位符 `$n`→`?` |
| `.env.local` / `.env.example` | `DATABASE_URL=mysql://transfer:****@127.0.0.1:3306/meeting_ai`（凭据见 .env.local，**密码含句尾句点**） |
| 新增脚本 | `scripts/db/create-mysql-database.mjs`（幂等建库 + 连通验证） |
| `scripts/db/setup-postgres.ps1` | 保留仅作历史记录，已不使用 |

## 3. 权限与初始化（已完成）

- `transfer` 账号原为空权限（仅 USAGE），已由老总用管理员账号执行一次性授权：
  ```sql
  CREATE DATABASE IF NOT EXISTS meeting_ai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  GRANT ALL PRIVILEGES ON meeting_ai.* TO 'transfer'@'';
  FLUSH PRIVILEGES;
  ```
- 表结构（meetings / app_settings / migration_markers）由应用启动时 `bootstrap.ts` 自动创建，无需手工执行 DDL。
- 存量数据：4 条会议已从 `.data/meetings.json` 迁入 MySQL（标记 `meetings_json_v1`，JSON 源文件与 .bak 备份保留只读）。
- `app_settings` 当前为**空配置**（initialized=false）：老总真实 API 密钥会在浏览器首次访问时由前端自动上报，或在设置弹窗重填一次。
